# Тренажёр «Нарушения стандартов: Борт, Фасовка, Фритюр»

Интерактивный тренажёр для менеджеров смены на дизайн-системе KU.
24 рабочие ситуации на станциях Борт, Фасовка и Фритюр с разбором каждого ответа.

- **Подраздел ДС:** `data-audience="ms" data-direction="stancii"` (Менеджер смены · Станции и касса)
- **Идентификатор для LMS:** `ku-bort-fasovka-fritur`
- **Источник сценария:** `input/Борт, фасовка, фритюр/Тренажер Нарушение стандартов… .docx`

## Предпросмотр

```bash
cd courses/bort-fasovka-fritur
python3 -m http.server 8000
# открыть http://localhost:8000/
```

Курс самодостаточен: работает офлайн, без сборки, CDN и внешних шрифтов.

## Структура

| Экран | id | Что там |
|---|---|---|
| Обложка и инструкция | `home` | Лид, три шага «как работает», цель, вход в материалы, кнопка «Конечно!» и «Продолжить» при сохранённом прогрессе |
| Материалы | `mat` | 3 памятки (PDF) + таблица сроков хранения + исходный `.xls`. Доступны с любого экрана — кнопка «Материалы» в шапке |
| Ситуации 1–24 | `s1`…`s24` | Одна ситуация — один экран, прогресс «7 / 24» в шапке |
| Финал | `finish` | Счёт, список ситуаций с ошибкой, сводка наставнику, кнопка «Завершить тренажёр» |

## Механики

Одна общая логика на все ситуации: **отметить → «Ответить» → разбор → «Далее»**.
Кнопка «Далее» появляется только после ответа.

| Ситуации | Механика |
|---|---|
| 1 | Перетаскивание по трём зонам (Борт / Фасовка / Другая станция). При ошибке чипы раскладываются по верным зонам и подсвечиваются |
| 2, 7 | Множественный выбор (квадратный маркер) |
| 3–6, 8–23 | Одиночный выбор (круглый маркер) |
| 24 | Аудит по 7 фотографиям: клик — синяя рамка, после проверки зелёная / красная / жёлтая («пропущено») + подпись-разбор под каждым фото. Значок лупы открывает фото крупно |

Разбор показывается и при верном, и при неверном ответе — так требует сценарий.
После ответа задание блокируется: неверно выбранные варианты краснеют, пропущенные
верные подсвечиваются жёлтым. Это разбор, а не наказание — прохождение дальше не блокируется.

### Почему свой движок, а не `.ku-choice[data-correct]` из ДС

Штатная механика ДС проверяет вариант мгновенно по клику и не умеет показывать
разбор неверного ответа. Сценарию нужен текст «если сотрудник ответил НЕ верно»,
поэтому здесь отложенная проверка (docs/MECHANICS.md §3). Разметка и состояния —
родные ДС; добавлены только `.is-picked` и `.missed`. Делегирование `kuds.js`
гасится `stopPropagation()` на контейнере `[data-picks]`.

## Прогресс и SCORM

Всё в `js/ku-scorm.js` — в курсе SCORM-кода нет.

- Ответы хранятся одной компактной строкой из 24 символов (`1` / `0` / `-`)
  в переменной `otvety` — чтобы уместиться в лимит `cmi.suspend_data` (4096 символов).
- В сводку наставнику попадают только `itog` и `oshibki`.
- После перезагрузки курс восстанавливает разбор каждой пройденной ситуации
  и предлагает «Продолжить с ситуации N».
- Завершение — **только** кнопкой «Завершить тренажёр» на финале.
- Каждый ответ дублируется в `cmi.interactions` через `KU.lms.interaction()`.

**Упаковка в SCORM не делалась.** Когда понадобится:
`python3 ../../kuds-ds/tools/scorm_pack.py .`

## Графика

Реальные фотографии сценария лежат в `assets/img/foto-01…09` (сжаты до ≤1600 px).

Недостающая графика оформлена **заглушкой** `.ku-gen`: пока файла нет, на его месте
плашка с названием, путём и кнопкой «Показать промт».

| Файл | Статус |
|---|---|
| `assets/img/hero.jpg` | **нужно сгенерировать** — обложка, 16:9 |
| остальные 9 | фото уже есть; 3D-промт вшит на случай перевода всего визуала в единый стиль |

Промты собраны по `prompt_assembly.recommended_order` из
`input/burger_king_style_3d_animation.ru.json` (стиль `stylized_3d_family_animation`)
и лежат в двух местах:

- `assets/img/PROMPTS.md` — списком, для человека;
- прямо в `index.html` рядом с каждым слотом:
  `<script type="application/json" data-gen-prompt="hero">{…}</script>`.

Агенту-генератору: положи готовый файл по пути из промта — заглушка подставит
картинку сама, разметку править не нужно.

## Правки сценария

Опечатки исходного `.docx` исправлены при переносе: «Неправиль!» → «Неправильно!»,
«ищевой» → «пищевой», «длжно» → «должно», «видшь» → «видишь», «перезапускат» →
«перезапускать», «способи» → «способ и».

Два места правились по смыслу — **проверьте у методиста**:

1. **Ситуация 12.** В оригинале: «При распылении на поверхность средство может
   попасть на поверхность». Написано: «…может попасть на продукт».
2. **Ситуация 24.** В оригинале перечислены «Картинки 2,3,4,5,6,7,8», а верными
   названы «3,4,5,6,7,8,9», и подписей ровно семь — к картинкам 3–9.
   В тренажёр взяты картинки 3–9 (7 фото, все с нарушением).

Ещё одно расхождение оставлено как есть: в ситуации 2 разбор говорит, что
замороженный картофель хранится «в фасовочной машине» — так в оригинале.
